# Random Image API V1 快照

> 本页从本地提交 `8235e19` 的 `README.md` 提炼，仅用于保存 V1 的行为与运维基线，不是逐字归档。V2 的使用方法见项目根目录 [README.md](../README.md)。

## 定位

V1 是面向单机长期运行的随机图片服务，采用 FastAPI、SQLite、本地永久图库、可选 WebDAV Hybrid 和 Docker Compose。设计重点是简单、可靠、低资源占用、可备份及可迁移。

## 核心能力

- `GET /random` 根据 User-Agent 判断 Desktop / Mobile；`?type=desktop` 或 `?type=mobile` 可显式覆盖。
- Desktop 优先横图，Mobile 优先竖图；一侧没有图片时可按配置回退。
- 支持 JPG、JPEG、PNG、WebP，按真实宽高分类；正方形策略可配置。
- `GET /health` 报告服务、数据库、本地图库、WebDAV 与缓存状态。
- SQLite 保存图片元数据和 WebDAV 索引，避免每次请求全盘扫描。
- 默认 `local`；可选 `hybrid`，默认以 90% 概率优先 WebDAV，并在远端失败时降级。
- WebDAV 图片按需下载到有界缓存，支持条件刷新、LRU 淘汰和随机轮换。
- importer 支持安全导入 ZIP、TAR.GZ、TGZ，按真实方向分类并按内容去重。
- `scripts/backup.sh` 与 `scripts/restore.sh` 支持图库和 SQLite 的备份恢复。

## V1 数据布局

```text
data/
├── images/
│   ├── desktop/
│   └── mobile/
├── database/images.db
├── cache/webdav/
└── logs/
```

正式部署使用 Docker Compose，把宿主机 `./data` 挂载到容器 `/app/data`。镜像不包含生产图片、数据库、日志、备份或私密配置。

## V1 运维接口

配置 `ADMIN_TOKEN` 后，可通过 `X-Admin-Token` 调用：

- `POST /admin/rescan`
- `POST /admin/webdav/sync`
- `POST /admin/cache/maintain`

V1 没有 V2 的主题标签 API 与浏览器管理 UI。
